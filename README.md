## 📌 About The Project

**Neon Glass Profile** is a modern and interactive personal profile card designed with a futuristic neon theme.

The project combines **Glassmorphism**, **Neon UI**, smooth animations, and JavaScript interactions to create an eye-catching web experience.

It is designed to demonstrate how basic web technologies can be used to create a visually advanced interface without using any external libraries or frameworks.

## 🎨 Design Highlights

### 💎 Glassmorphism

The profile card uses a transparent glass-like background with:

- `backdrop-filter`
- Transparent borders
- Soft shadows
- Blur effects

This creates a modern glass UI appearance.

### ⚡ Neon Effects

The interface uses glowing cyan and purple effects to create a futuristic appearance.

Neon effects are applied to:

- Profile avatar
- Buttons
- Borders
- Background particles
- Cursor glow
- Scanning line

### 🧊 3D Tilt Effect

Moving the mouse over the profile card creates a subtle 3D rotation effect.

JavaScript calculates the mouse position and dynamically changes:

```javascript
rotateX()
rotateY()
```

This makes the card feel interactive instead of static.

### ⌨️ Typewriter Animation

The profile automatically cycles through different roles:

```text
Frontend Developer
Creative Coder
Web Designer
Python Learner
```

The text is typed and deleted dynamically using JavaScript.
